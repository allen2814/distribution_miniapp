# 达人中心（Expert Center）

## 项目简介

达人中心是基于 uni-app 框架开发的多端应用，支持 App、H5、小程序等多平台运行。项目聚焦于达人内容管理、收益统计、专辑与故事管理、提现等功能，适用于内容创作者、达人及其运营团队。

## 主要功能
- 专辑管理：专辑的创建、编辑、详情查看与列表展示
- 故事管理：故事内容的发布、编辑、详情与列表
- 收益统计：可视化 Echarts 图表展示达人收益数据
- 资源推广：达人资源的管理与推广
- 提现管理：支持提现申请、记录查询
- 用户中心：用户信息管理、登录与权限控制

## 技术栈
- 前端框架：uni-app（Vue 3）
- 状态管理：Pinia
- 可视化：Echarts（通过 uni_modules/qiun-data-charts）
- 构建工具：Vite
- 适配平台：App（5+）、H5、微信/支付宝/百度/头条小程序

## 目录结构
- `src/pages/`：各业务页面（专辑、故事、收益、提现等）
- `src/components/`：通用组件（如弹窗、内容卡片等）
- `src/api/`：接口请求与数据模型
- `src/stores/`：Pinia 状态管理
- `src/config/`：全局配置
- `src/models/`：数据类型与模型
- `src/utils/`：工具函数
- `uni_modules/`：第三方 uni-app 模块

## 运行与打包
1. 安装依赖：
   ```powershell
   npm install
   ```
2. 本地开发（H5）：
   ```powershell
   npm run dev:h5
   ```
3. App 打包：
   - 推荐使用 HBuilderX 打开项目，配置 manifest.json 后点击“发行”进行 App 打包。

## 适用场景
- 内容创作者管理个人内容与收益
- 运营团队管理达人资源
- 需要多端适配的内容管理平台
